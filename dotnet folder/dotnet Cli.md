The **.NET CLI** is a command-line tool that allows you to **create, build, run, test, publish, and manage .NET applications** without using an IDE like Visual Studio.

You interact with it using the `dotnet` command.

|Serial|Command|Description|
|---|---|---|

|   |   |   |
|---|---|---|
|1|`dotnet --help`|Display general help information.|

|   |   |   |
|---|---|---|
|2|`dotnet --version`|Display the current .NET SDK version.|

|   |   |   |
|---|---|---|
|3|`dotnet --info`|Display detailed .NET SDK and runtime information.|

|   |   |   |
|---|---|---|
|4|`dotnet --list-sdks`|List all installed .NET SDKs.|

|   |   |   |
|---|---|---|
|5|`dotnet --list-runtimes`|List all installed .NET runtimes.|

|   |   |   |
|---|---|---|
|6|`dotnet new`|Create a new project, solution, or file from a template.|

|   |   |   |
|---|---|---|
|7|`dotnet restore`|Restore NuGet package dependencies.|

|   |   |   |
|---|---|---|
|8|`dotnet build`|Build (compile) a project or solution.|

|   |   |   |
|---|---|---|
|9|`dotnet run`|Build and run a project.|

|   |   |   |
|---|---|---|
|10|`dotnet clean`|Remove build output files.|

|   |   |   |
|---|---|---|
|11|`dotnet publish`|Produce deployment-ready application files.|

|   |   |   |
|---|---|---|
|12|`dotnet pack`|Create a NuGet package from a project.|

|   |   |   |
|---|---|---|
|13|`dotnet test`|Run unit tests.|

|   |   |   |
|---|---|---|
|14|`dotnet vstest`|Run tests using the Visual Studio Test platform.|

|   |   |   |
|---|---|---|
|15|`dotnet msbuild`|Execute MSBuild commands.|

|   |   |   |
|---|---|---|
|16|`dotnet sln`|Create and manage solution (`.sln`) files.|

|   |   |   |
|---|---|---|
|17|`dotnet add package`|Add a NuGet package reference.|

|   |   |   |
|---|---|---|
|18|`dotnet add reference`|Add a project reference.|

|   |   |   |
|---|---|---|
|19|`dotnet remove package`|Remove a NuGet package reference.|

|   |   |   |
|---|---|---|
|20|`dotnet remove reference`|Remove a project reference.|

|   |   |   |
|---|---|---|
|21|`dotnet list package`|List package references.|

|   |   |   |
|---|---|---|
|22|`dotnet list reference`|List project references.|

|   |   |   |
|---|---|---|
|23|`dotnet list project-to-project`|List project-to-project references.|

|   |   |   |
|---|---|---|
|24|`dotnet tool install`|Install a .NET CLI tool.|

|   |   |   |
|---|---|---|
|25|`dotnet tool uninstall`|Uninstall a .NET CLI tool.|

|   |   |   |
|---|---|---|
|26|`dotnet tool update`|Update an installed .NET CLI tool.|

|   |   |   |
|---|---|---|
|27|`dotnet tool restore`|Restore local .NET CLI tools.|

|   |   |   |
|---|---|---|
|28|`dotnet tool list`|List installed .NET CLI tools.|

|   |   |   |
|---|---|---|
|29|`dotnet nuget`|Manage NuGet configuration, sources, and caches.|

|   |   |   |
|---|---|---|
|30|`dotnet workload install`|Install a workload.|

|   |   |   |
|---|---|---|
|31|`dotnet workload uninstall`|Uninstall a workload.|

|   |   |   |
|---|---|---|
|32|`dotnet workload update`|Update installed workloads.|

|   |   |   |
|---|---|---|
|33|`dotnet workload restore`|Restore required workloads.|

|   |   |   |
|---|---|---|
|34|`dotnet workload search`|Search available workloads.|

|   |   |   |
|---|---|---|
|35|`dotnet workload list`|List installed workloads.|

|   |   |   |
|---|---|---|
|36|`dotnet watch`|Watch for file changes and rerun commands automatically.|

|   |   |   |
|---|---|---|
|37|`dotnet format`|Format source code according to .NET coding conventions.|

|   |   |   |
|---|---|---|
|38|`dotnet dev-certs`|Manage HTTPS development certificates.|

|   |   |   |
|---|---|---|
|39|`dotnet fsi`|Start the F# Interactive shell (if installed).|

|     |               |                                      |
| --- | ------------- | ------------------------------------ |
| 40  | `dotnet exec` | Execute a .NET application directly. |
