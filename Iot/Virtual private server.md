A server is called a **VPS (Virtual Private Server)** ==when a single physical computer is split into multiple isolated, private environments using software==.

To be officially called a VPS, the setup must meet three specific conditions:

- **It must be Virtual:** The server does not exist as its own physical box. It is a digital slice of a larger machine created by a software layer (hypervisor).
- **It must be Private:** Your slice is completely locked away from other users. You get your own dedicated resources (like CPU power and RAM) and your own unique IP address. No one else on that machine can see your files or steal your performance.
- **It acts like a real Server:** You get full administrator access (called "root access"). This allows you to install any operating system, change any setting, and run any software you want—just like you would on a physical computer.
