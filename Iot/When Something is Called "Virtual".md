A technology is called **virtual** ==when it is created by software instead of existing as a real, physical object==.
We call a technology virtual when software mimics physical hardware to do these three things: 
- **Splits one into many:** A single, massive physical computer is divided into dozens of smaller, independent "virtual" computers.
- **Hides the real hardware:** The software blocks you from seeing the actual cables, chips, and disks in the data center.
- **Acts exactly like the real thing:** A virtual hard drive behaves exactly like a real one, allowing you to save files and install programs normally.
