**Space complexity** is ==a measure of how much **extra memory** (RAM) a program needs to finish as your input data grows **bigger**==.

he Two Components of Space Complexity

When calculating space, we look at two distinct parts:

1. **Fixed Space (Input Space):** The memory required by the input data itself (e.g., an array passed into a function).
2. **Auxiliary Space (Extra Space):** The temporary memory allocated by the algorithm to solve the problem (e.g., creating a new loop variable or a temporary list)
