Object-Oriented Programming (OOP) is a software design model that organizes code around "objects" rather than logic. . It groups related data and functions together into self-contained units, making large or complex programs easier to manage, scale, and reuse
# OOP offers several distinct advantages:
- **Reusability:** You can write a class once and use it multiple times, keeping code DRY (Don't Repeat Yourself).

- **Maintainability:** Modular code isolates different parts of the software, meaning changes or bug fixes can be made to one class without affecting the entire program.

- **Scalability:** You can easily add new features and objects as the system grows.
